Что делает расширение

Path Tracer for n8n — неофициальное расширение для редактора n8n. Оно читает открытый в браузере воркфлоу: узлы и связи из DOM страницы и клиентского состояния редактора. На их основе расширение рисует поверх канваса цветные маршруты от триггера до выбранного узла и позволяет изолировать один маршрут кликом по связи.

Вся обработка происходит локально на устройстве пользователя. Содержимое воркфлоу не передаётся, не сохраняется и не используется ни для каких других целей.

Какие данные собираются

Никакие. Расширение не собирает персональные данные, не ведёт статистику использования, не отправляет телеметрию и не создаёт профили.

Сетевые запросы и удалённый код

  • Расширение не выполняет сетевых запросов.
  • Не загружает удалённые скрипты, стили, шрифты или конфигурацию.
  • Не обращается к API n8n и не требует API-ключей.
  • Не использует сторонние SDK и аналитические сервисы.

Хранение данных

Расширение не использует браузерное хранилище: chrome.storage, cookies, localStorage, sessionStorage, IndexedDB и кэш. Настройки не сохраняются; состояние трассировки живёт только до перезагрузки страницы.

Разрешения и доступ к сайтам

Расширение не запрашивает API-разрешения (permissions и host_permissions пусты). Единственный content script объявлен на http://*/* и https://*/*, потому что n8n можно развернуть на любом домене, включая self-hosted.

На каждой странице скрипт сначала проверяет, что это редактор n8n: наличие мета-тега n8n:config:rest-endpoint или канваса n8n (/workflow/* и .vue-flow). Если проверка не пройдена, скрипт сразу завершается: ничего не читает, не изменяет и не создаёт элементы на других сайтах.

Данные не передаются: передавать нечего, расширение не собирает и не хранит информацию. Третьи стороны не используются.

Дети

Расширение не предназначено для детей и не собирает данные о них.

Изменения политики

При изменении поведения расширения политика обновляется вместе с релизом; дата обновления указана в начале страницы.

Контакт

Вопросы по приватности — через Issues в репозитории проекта; ссылка на репозиторий указана в листинге Chrome Web Store.

Статус и лицензия

Path Tracer for n8n не связано с n8n, не одобрено и не спонсируется n8n. Код распространяется по лицензии MIT.

Коротко для ревью Chrome Web Store: расширение не собирает и не передаёт пользовательские данные, не загружает удалённый код, не использует хранилище и не запрашивает API-разрешения. Широкий доступ к сайтам нужен только для самохостинговых установок n8n; на остальных страницах скрипт сразу завершается.

Privacy Policy

Last updated: 3 November 2026 · Path Tracer for n8n v1.4.0

Summary

Path Tracer for n8n is an unofficial browser extension for the n8n workflow editor. It processes the workflow locally in the browser and does not collect, store, or transmit any data.

Data collection

None. No personal data, analytics, telemetry, identifiers, or usage statistics are collected.

Network and remote code

The extension makes no network requests, loads no remote code, and does not call the n8n API.

Storage

No browser storage is used: no chrome.storage, cookies, localStorage, sessionStorage, IndexedDB, or cache.

Permissions and site access

The extension declares no API permissions and no host permissions. Its content script is matched against all HTTP(S) pages because n8n can be self-hosted on any domain. On every page it first verifies that the page is an n8n editor (the n8n:config:rest-endpoint meta tag or the n8n canvas at /workflow/* with .vue-flow). Otherwise it exits immediately and does nothing.

Third parties

None. No third-party services are used and no data is shared.

Changes and contact

The policy is updated together with releases. Contact: project repository Issues.

Status and license

Not affiliated with, endorsed by, or sponsored by n8n. Released under the MIT license.
