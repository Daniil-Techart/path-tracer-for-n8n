# Совместимость с n8n

Проверено: 2026-11-01, расширение 1.4.0.

## Что считается поддерживаемым

На момент проверки (по dist-tags npm и релизам n8n):

| Линия | Версия | Статус |
| --- | --- | --- |
| stable | 2.45.7 | текущий стабильный релиз |
| beta | 2.46.3 | следующий стабильный кандидат |
| v1 | 1.123.91 | security-фиксы до 31.12.2026 |
| v3 beta | 3.0.1 | beta, stable ожидается в начале декабря 2026 |

Политика n8n:

- 1.x поддерживается до 31.12.2026 (только security).
- После выхода 3.0 stable линия 2.x получает security и критические фиксы ещё 12 месяцев.
- Security-обновления сейчас выходят для линий 1.123.x и 2.41–2.46 (каждые две недели).
- n8n Cloud обновляется автоматически, редактор соответствует актуальной 2.x/3.x.

## Матрица проверки

Метод: для каждой версии поднимался отдельный Docker-контейнер, создавался воркфлоу
`Trigger → Node1 → (Node2 | Node3) → End`, расширение загружалось в Chromium, затем проверялись:
активация кнопки, 2 пути, 2 цвета (общий участок одного цвета, ветки разные), отсутствие пунктира,
изоляция пути кликом и единый цвет изолированного пути.

| Версия n8n | Линия | Источник графа | Пути | Цвета по веткам | Клик-изоляция | Итог |
| --- | --- | --- | --- | --- | --- | --- |
| 1.123.91 | v1 (supported до 31.12.2026) | DOM fallback | 2 | да | да, один цвет | ✅ |
| 2.41.7 | 2.x (старейшая патчимая) | pinia store | 2 | да | да, один цвет | ✅ |
| 2.45.7 | stable | pinia store | 2 | да | да, один цвет | ✅ |
| 2.46.3 | beta | pinia store | 2 | да | да, один цвет | ✅ |
| 3.0.1 | v3 beta | pinia store | 2 | да | да, один цвет | ✅ |

Дополнительно проверено на 2.46.0: синхронизация геометрии при перетаскивании узлов,
анимация, включение/выключение кнопкой, работа в строгом CSP (тесты расширения).

## Как перепроверить

```powershell
npm run compat -- 1.123.91 2.41.7 2.45.7 2.46.3 3.0.1
```

Скрипт `scripts/compat.mjs` требует Docker, Chromium/Edge и `puppeteer-core`
(он уже в devDependencies). Каждая версия запускается на порту 5680 во временном
контейнере и удаляется после проверки.

## Ограничения

- Реальный Cloud-тенант не проверялся (нет доступа), но редактор Cloud собирается из тех же
  пакетов `n8n-editor-ui`, что и self-hosted соответствующей линии.
- Версии 1.0–1.122 и 2.0–2.40 не входят в текущую поддержку security-фиксов и не проверялись.
- Плагин завязан на разметку редактора (Vue Flow, `data-node-name`, pinia-стор). При крупных
  изменениях канваса в будущих мажорах потребуется обновление — матрицу нужно перепрогонять.
